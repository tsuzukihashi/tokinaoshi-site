このポリシーの要旨
ときなおしは、インターネットに一切つながらないアプリです。アカウント登録やログインはなく、名前やメールアドレスを尋ねることもありません。広告、分析ツール、クラッシュを報告する仕組み、外部の会社の SDK は入れていません。解いた記録と設定は、あなたの iPhone の中だけに保存し、開発者を含めて、どこにも送りません。

1. 提供者

提供者續橋涼（個人開発者 / TsuzuKit）
アプリ名ときなおし
対象iPhone 向けアプリと、このページを含む https://tokinaoshi.tsuzukit.com/ 配下のページ
連絡先ryo.tsuzukihashi@tsuzukit.com

2. 端末の中だけで扱うもの

解いた記録問題ごとの解いた回数と正誤、次に出す日、旗、終えた回の数、模擬試験の結果
設定試験日、1日に解く問題数、はじめの案内を終えたかどうか

どちらも iPhone の中にだけ保存します。開発者のサーバーにも、ほかの会社にも送りません。アプリを削除すると消えます。iPhone のバックアップ（iCloud バックアップなど）を使っている場合は、Apple の仕組みでバックアップに含まれます。

3. 通信と、入れていないもの

本アプリは通信をしません。機内モードでも、すべての機能が使えます。次のものは入れていません。

  • 広告
  • アプリ内課金とサブスクリプション
  • アカウント登録とログイン
  • 利用状況を計測する分析ツール
  • クラッシュを報告する仕組み
  • 外部の会社の SDK

4. アプリの外へのリンク

本アプリから外のページへのリンクは、このサイトの紹介・利用規約・プライバシーポリシー・「誤りを知らせる」ページだけです。押すと Safari で開きます。「誤りを知らせる」ページには、問題の番号（例: ds-DS-091-1）だけが渡ります。あなたが誰か、どう答えたかは渡りません。

5. 購入

本アプリは App Store の有料アプリです。お支払いは Apple が処理し、カードなどの支払いの情報は開発者には届きません。アプリの中で購入を求めることはありません。

6. 情報を使う目的

解いた記録と設定は、アプリを動かすためだけに iPhone の中で使います。お問い合わせや誤りの報告をいただいたときは、いただいたメールアドレスと内容を、お返事と問題の修正のためだけに使います。法令にもとづく場合を除き、本人の同意なく第三者に渡すことはありません。

7. 消したいとき

アプリの設定の「解いた記録を全部消す」で、記録を消せます。アプリを削除すると、記録と設定はすべて消えます。開発者はその控えを持っていません。

8. このウェブサイトについて

このサイト（tokinaoshi.tsuzukit.com）は、Cookie も、アクセスを計測する仕組みも、広告も使っていません。サイトは GitHub Pages で配信しており、配信の記録（IP アドレスなど）は GitHub の プライバシーについての声明 に沿って扱われます。

9. 改定

このポリシーを変えるときは、このページを書きかえ、上の改定日を新しくします。大事な変更のときは、アプリの更新の説明にも書きます。
